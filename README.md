# 智能问数插件（测绘版）0.8.3-dev.5

智能问数在 DeepSeek Harness 会话中查询项目授权的数据，核算指标，并在回答下方展示表格、图形和查询依据。

1. 在宿主插件管理器上传同批交付的单个 TGZ，查看组件和引擎状态。备份、升级与回退见 [部署说明](DEPLOYMENT.md)。
2. 在配置管理中连接数据库、选择业务项目及授权表，保存草稿并发布。基础查询可以直接使用授权字段。
3. 需要测绘业务口径时，核对内置 v2.1 资料导入的草稿，再由管理员发布。新建问数会话时选择该项目。

本包内置业务资料来自《测绘地理信息管理_二级指标查询SQL示例表_v2.1.xlsx》。工作簿和来源行索引随 `build-info.json` 所指载荷的 `business/` 目录提供。176 项指标中，169 项有查询示例，7 项缺可比历史时不可计算。示例期间、范围和字段按项目的授权来源核对，已发布的口径由管理员维护。

配置管理按需加载项目详情，保留三个活跃恢复点并归档较早快照。图形依据数据形态与用户要求选择，测试数据在回答中明确标注。

一个宿主进程对应一个受信任操作人。凭据和数据目录边界见 [安全说明](SECURITY.md)。构建身份见 `build-info.json`，本次修改见 [变更记录](CHANGELOG.md)，实际结果以同一 TGZ 哈希的 [验收记录](VERIFICATION.md) 为准。
